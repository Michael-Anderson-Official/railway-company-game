# 鉄道会社経営ゲーム — 刈谷市地下鉄構想

スマートフォン縦画面対応の、地下鉄構想用地図・配線エディタの試作版です。

公開先：<https://michael-anderson-official.github.io/railway-company-game/>

## 現在できること

- 刈谷市の実際の地図（国土地理院の標準地図）と、白紙の配線図を切り替え
- 1面2線の島式ホームを2〜16両から指定して配置。1両20mで算定（2両40m〜16両320m）し、刈谷市の地図上では地理院タイルのWebメルカトル座標に実距離で合わせた長さ・幅で表示。既に置いたホームの両数は維持
- 配置済みの駅をタップ／クリックして選択。線路未接続の駅は駅本体のドラッグで移動し、紫の回転ハンドル「↻」または角度スライダーで自由回転できる。線路接続後は接続部分が破断しないよう駅の移動・回転をロック
- 駅を配置すると「新駅1」「新駅2」…の仮称を付与。駅を選択して下部の「駅名」欄に好きな名前を入力すると、刈谷市の地図・白紙のどちらでも駅名ラベルを即時更新。選択を切り替えても編集した駅名を保持（現状、ページ再読み込みで配置データとともに初期化）
- 「複線」ボタンで、**地図上の行き先を1回タップするだけで、その場所まで自然な曲線を自動生成**。接続元は駅の左右の空き線路端・既設複線の先端から選択でき、反対向きの端を選んでいた場合も到達可能な別の空き端へ自動切替。延長や角度の手入力・自由ドラッグ敷設は不要。青いプレビューで到達地点・自動計算された延長を確認し、敷設ボタンで確定。指のドラッグは地図移動、2本指はピンチズームとして使用
- 自動生成曲線は、接続元の進行方向から曲率0で出発し、終点でも曲率0になるように接線方向を滑らかに変化させ、指定した地点を厳密に終点とする。最小曲線半径160m（内側軌道分も考慮）、1区間の最大方向変化90°、既存線路への接近・交差・重複の拒否、他駅のホーム・構内への食い込みの拒否、空き線路端の一度きりの使用（ポイントなしで分岐禁止）を簡易判定。現実的に到達できない点は敷設不可理由を表示し、終点の再指定を案内
- 刈谷市の実距離地図では駅構内の線路中心間隔12mから、最初の120mで複線の仮基準4mに漸減。広域表示では重ならないよう4m区間の**見た目のみ**を離し、詳細表示で実寸へ戻す。**4mは車両規格未設定のゲーム上の暫定値で、法定の一律基準ではない**（国交省の解釈基準では車両限界の幅に所要余裕を加える）。白紙モードは地理縮尺がないため概略表示
- ピンチイン・ピンチアウトで基準の0.1〜16倍に縮尺変更。画面上の＋／−ボタンからも操作可能
- 刈谷市の地図を指で移動して位置を確認
- JR東海道本線・名鉄名古屋本線・名鉄三河線に属する市内8駅を地図上に表示
- 主要商業施設5か所と工業拠点3か所を代表地点として表示
- 刈谷市の地下鉄新駅から半径800mの徒歩集客圏を実距離で表示。選択駅は400m・600m・800mの同心円を表示し、距離帯ごとの集客係数100%・65%・30%で潜在利用人口を試算
- 国土交通省の2025年推計250m人口メッシュを16分割して集客計算。複数駅の圏域が重なるときは各人口標本を最寄りの建設駅に一度だけ割り当て、人口を二重計上しない。駅の追加・移動に追従して数字を更新

現段階では「列車運行・運賃収入・収支のシミュレーション」はまだ実装していません。潜在利用人口は駅への距離から計算した人口換算値であり、実際の乗車人数・運行需要予測ではありません。白紙モードには地理情報がないため、集客計算は適用しません。

**線路の安全判定の範囲：** 現在は同一平面の簡易形状チェックです。軌間・車両限界の最終決定、カント、緩和曲線の詳細設計、線路の勾配、橋・トンネル、用地、支障物、信号・分岐器、構造物との離隔は未判定です。現実の敷設許可や施工設計の代用にはなりません。参照：[国土交通省・鉄道に関する技術上の基準を定める省令等の解釈基準（PDF）](https://www.mlit.go.jp/common/001968198.pdf) 第14条（曲線半径）、第22条（建築限界・車両限界と線路中心間隔）。

駅・施設の緯度経度は公開地図情報を照合して手入力した近似位置です。駅位置については OpenStreetMap の協力者による地図情報を参照しています。商業施設は刈谷ハイウェイオアシス、イオンタウン刈谷、ルビットタウン刈谷、アピタ刈谷、みなくる刈谷の5件、工業拠点はデンソー本社・高棚製作所、豊田自動織機本社・刈谷工場の3件です。

地図モードではホーム長を「指定両数 × 20m」で換算し、設置位置の緯度に応じた地上距離で表示します。島式ホームの幅は仮に8m、線路中心はホーム中心から各6m、線路はホームの両端から各20m延伸として描画します。白紙モードは地図縮尺を持たない従来の配線略図です。

**集客計算：** `population-kariya-2025.json` は上記国交省の「250m_mesh_2024_23_GEOJSON.zip」から刈谷市（市区町村コード23210）の2025年推計総人口が正のメッシュを抽出したものです。`python3 extract_kariya_population.py <元ZIPのパス>` で再生成できます。各メッシュを4×4点に細分化し、各点を徒歩800m以内の**最寄りの設置駅1駅のみ**に割り当てます。距離0〜400mは1、400〜600mは0.65、600〜800mは0.30を掛けた人口が「潜在利用人口」です。この集客係数はゲーム独自の仮定であり、鉄道利用率の統計ではありません。道路距離・改札位置・運行本数・運賃・路線接続・商業施設への流動はまだ考慮していません。

**データの範囲：** 市人口153,200人は2026年10月時点の住民基本台帳実績、人口メッシュ計約155,197人は2020年国勢調査を基準にした2025年の国交省推計であり、定義・年度が異なります。2026年町別人口CSVは出典として案内していますが、個別の町界ポリゴンや同CSVの人口割り当ては行っていません。全商店・全事業所の位置や現在の乗降者数を網羅したものではありません。現実の地下鉄計画に必要な道路・地質・工費等も未評価です。

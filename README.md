# 鉄道会社経営ゲーム — 刈谷市地下鉄構想

スマートフォン縦画面対応の、地下鉄構想用地図・配線エディタの試作版です。

公開先：<https://michael-anderson-official.github.io/railway-company-game/>

## 現在できること

- 刈谷市の実際の地図（国土地理院の標準地図）と、白紙の配線図を切り替え
- 1面2線の島式ホームを2〜16両から指定して配置。既に置いたホームの両数は維持
- ピンチイン・ピンチアウトで基準の0.1〜16倍に縮尺変更。画面上の＋／−ボタンからも操作可能
- 刈谷市の地図を指で移動して位置を確認
- JR東海道本線・名鉄名古屋本線・名鉄三河線に属する市内8駅を地図上に表示
- 主要商業施設5か所と工業拠点3か所を代表地点として表示

現段階では「地下鉄建設・運行・収支のシミュレーション」はまだ実装していません。ホーム配置と地図の土台までです。

駅・施設の緯度経度は公開地図情報を照合して手入力した近似位置です。駅位置については OpenStreetMap の協力者による地図情報を参照しています。商業施設は刈谷ハイウェイオアシス、イオンタウン刈谷、ルビットタウン刈谷、アピタ刈谷、みなくる刈谷の5件、工業拠点はデンソー本社・高棚製作所、豊田自動織機本社・刈谷工場の3件です。

**データの範囲：** 市人口は最新公表の全市集計、商業・乗降はそれぞれ別年度の公表実績です。2026年町別人口CSVは出典として案内していますが、今回の地図に町界ポリゴンや人口メッシュは含めていません。全商店・全事業所の位置や現在の乗降者数を網羅したものではありません。現実の地下鉄計画に必要な道路・地質・工費等も未評価です。

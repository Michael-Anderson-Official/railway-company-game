# 鉄道会社経営ゲーム — 刈谷市・知立市・豊明市地下鉄構想

スマートフォン縦画面対応の、地下鉄構想用地図・配線エディタの試作版です。

公開先：<https://michael-anderson-official.github.io/railway-company-game/>

## 現在できること

- **地図優先のスマホUI：** 縦画面では上部を細いタイトルバーにして地図を広く表示。駅・複線・車両基地・車両の4ボタンを下部ドックに配置。右上「設定」で地図切替・表示地域・階層・対応両数を開閉でき、現在の設定はタイトル直下に表示する。編集・購入パネルはドックの上に最大画面高の35〜39%で表示し、長い内容はそのパネルだけをスクロール。PCは従来の横並び操作を維持
- 刈谷市・知立市・豊明市周辺の実際の地図（国土地理院の標準地図）と、白紙の配線図を切り替え。「表示地域」から3市の中心部へ移動でき、建設した駅・複線の位置は維持される
- **地上（0m）と地下1〜5階（−10m、−20m、−30m、−40m、−50m）の6階層**を切り替えて駅・複線を配置。新規配置の初期階層は地下1階。駅と線路は階層別に保存され、選択した階層だけを表示・編集。別の階層では同じ平面位置に駅・線路を建設できる。駅と線路は同じ階層内でのみ接続し、階層間を結ぶ勾配線路は未実装
- 背景の国土地理院地図は従来の不透明度93%から62%に薄く表示し、新設する駅・複線を見やすくした。駅・施設マーカーは薄くせず表示
- 1面2線の島式ホームを2〜16両から指定し、**初期状態で上下（縦向き）**に配置。設置後は引き続き自由回転可能。1両20mで算定（2両40m〜16両320m）し、刈谷市の地図上では地理院タイルのWebメルカトル座標に実距離で合わせた長さ・幅で表示。既に置いたホームの両数は維持
- 配置済みの駅をタップ／クリックして選択。線路未接続の駅は駅本体のドラッグで移動し、紫の回転ハンドル「↻」または角度スライダーで自由回転できる。線路接続後は接続部分が破断しないよう駅の移動・回転をロック
- 駅を配置すると「新駅1」「新駅2」…の仮称を付与。駅を選択して下部の「駅名」欄に好きな名前を入力すると、刈谷市の地図・白紙のどちらでも駅名ラベルを即時更新。選択を切り替えても編集した駅名を保持（現状、ページ再読み込みで配置データとともに初期化）
- **既存の他社線への乗換設定：** 地図上で新駅を設置したとき、既存のJR・名鉄の駅の中心まで250m以内なら「知立駅（名鉄）に接続しますか？」などの確認を表示。「接続する」を選ぶと新駅のデータに既存駅・事業者・路線・距離を登録し、地図と駅情報欄に「乗換駅」と表示。「接続しない」なら通常駅。移動した駅が接続対象から250m以上離れた場合、乗換指定を解除。移動先が別の既存駅に近い場合は改めて確認。直線距離の暫定ゲームルールであり、実際の改札間距離・連絡通路の施工・所要時間は未判定
- 「複線」ボタンで駅端を**上り側／下り側**と表示。接続元を選び、接続先の駅端に表示される丸いマーカーをタップすると、**「〇〇駅の上り側に接続しますか？」**（下り側を選んだ場合は下り側）と確認ポップアップを表示。「接続する」で初めて建設され、「キャンセル」では建設されない。接続済みの端には重複してつなげず、接続した両駅を移動・回転ロックする。上り／下りは実際の運転系統を設定する前の仮称
- **駅と複線をつなぐと、その駅端にX字型のシーサスクロッシング（両方向の渡り線）を自動設置。**駅端から10〜110mの区間に2本の斜めの渡り線を描き、4か所で本線に接続する。駅と駅を直接つなぐ場合は両駅側にそれぞれ設置。既設の複線の先端から延ばすだけの場合は余分な渡り線を設けない。地図上では既設複線と同じ実距離で描き、白紙では概略配置。ポイント切替操作・列車の転線判定・分岐器の構造・工費はまだ未実装
- **車両カタログ・試運転：** 上部の「車両」から名鉄2200系（6両・ゲーム上120m）と京王5000系2代目（10両・ゲーム上200m）を選択し、実車の営業最高速度・起動加速度・常用／非常減速度・軌間・電圧などを閲覧。駅につながる既設複線を選んで「試運転開始」すると、1両20mの長さで描かれた編成が駅を出発し、加速・最高速度制限・終点への常用ブレーキ停止をシミュレート。1／5／10倍速、非常ブレーキ、終了・リセットに対応。6両ホームに10両編成は出せない。再読込で試運転設定は初期化
- **1線車両基地と車両購入：** 上部の「対応両数」で駅と共通の2〜16両を選び、「車両基地」ボタンで好きな階層・地図の地点に配置。配置した基地の留置有効長は選択両数×20m（両端に各10mの安全余長）。基地本体をマウスクリック／スマホでタップすると購入パネルが開き、名鉄2200系6両または京王5000系10両を1編成購入登録して留置線上に実寸で描画。6両基地に10両は購入不可、1線は1編成で満線となり、別の編成には別の基地が必要。基地は地図・階層ごとに独立し、保有編成数を表示する。**車両価格・会社資金・費用の控除は未実装であり、今回は無料の購入登録**。本線との接続・営業運用・再読込後の状態保存も未実装
- 従来どおり、**地図上の任意の行き先を1回タップ**してその地点まで自然な曲線を自動生成することも可能。接続元は空き駅端・既設複線の先端から選択でき、到達可能なら接続元を自動切替。任意の地点は青いプレビューと敷設ボタンで確定。指のドラッグは地図移動、2本指はピンチズーム
- **駅と駅の接続**は両方の駅端の接線方向を合わせ、曲率0から曲率0へ変化する曲線を探索。始発側と終着側それぞれ120mの間隔遷移を設け、駅構内の線路中心間隔12mへ正確に接続。最小曲線半径160mや線路交差などを満たせない場合は建設しない
- 自動生成曲線は、接続元の進行方向から曲率0で出発し、終点でも曲率0になるように接線方向を滑らかに変化させ、指定した地点を厳密に終点とする。最小曲線半径160m（内側軌道分も考慮）、1区間の最大方向変化90°、既存線路への接近・交差・重複の拒否、他駅のホーム・構内への食い込みの拒否、空き線路端の一度きりの使用（**駅端の渡り線以外には分岐を追加できない**）を簡易判定。現実的に到達できない点は敷設不可理由を表示し、終点の再指定を案内
- 刈谷市の実距離地図では駅構内の線路中心間隔12mから、最初の120mで複線の仮基準4mに漸減。広域表示では重ならないよう4m区間の**見た目のみ**を離し、詳細表示で実寸へ戻す。**4mは車両規格未設定のゲーム上の暫定値で、法定の一律基準ではない**（国交省の解釈基準では車両限界の幅に所要余裕を加える）。白紙モードは地理縮尺がないため概略表示
- ピンチイン・ピンチアウトで基準の0.1〜16倍に縮尺変更。画面上の＋／−ボタンからも操作可能
- 刈谷市の地図を指で移動して位置を確認
- JR東海道本線・名鉄名古屋本線・名鉄三河線に属する**刈谷市内8駅＋知立市内4駅＋豊明市内2駅**を地図上に表示。知立・三河知立（2024年3月移転後）・牛田・重原・豊明・前後を収録。中京競馬場前駅は隣接する名古屋市緑区に所在するため、豊明市内の2駅には含まれない
- 主要商業施設5か所と工業拠点3か所を代表地点として表示
- 3市の地下鉄新駅から半径800mの徒歩集客圏を実距離で表示。表示階層の駅だけ集客圏を描画し、集客人数の集計には全階層の駅を含める。選択駅は400m・600m・800mの同心円を表示し、距離帯ごとの集客係数100%・65%・30%で潜在利用人口を試算
- **3市の**国土交通省2025年推計250m人口メッシュを16分割して集客計算。複数駅の圏域が重なるときは各人口標本を最寄りの建設駅に一度だけ割り当て、人口を二重計上しない。駅の追加・移動に追従して数字を更新

現段階では個別区間の車両試運転はできますが、「運行ダイヤ・複数列車の運行管理・運賃収入・収支のシミュレーション」はまだ実装していません。潜在利用人口は駅への距離から計算した人口換算値であり、実際の乗車人数・運行需要予測ではありません。白紙モードには地理情報がないため、集客計算は適用しません。

**線路の安全判定の範囲：** 現在は各階層の同一平面だけを対象とする簡易形状チェックです。地下1階＝−10mなどの数値はゲーム内の設計深度であり、地表の起伏や実際の土被りは未反映です。軌間・車両限界の最終決定、カント、緩和曲線の詳細設計、階層間の勾配、橋・トンネル、用地、支障物、信号・分岐器、構造物との離隔は未判定です。現実の敷設許可や施工設計の代用にはなりません。参照：[国土交通省・鉄道に関する技術上の基準を定める省令等の解釈基準（PDF）](https://www.mlit.go.jp/common/001968198.pdf) 第14条（曲線半径）、第22条（建築限界・車両限界と線路中心間隔）。

| 実車の営業最高速度 | 120km/h | 110km/h |
| 設計最高速度（営業最高速度ではない） | 130km/h | 130km/h |
| 起動加速度 | 2.3km/h/s（65km/hまで） | 3.3km/h/s |

| 架線電圧 | 直流1,500V | 直流1,500V |
| 編成主電動機定格出力 | 2,040kW | 3,600kW（150kW×4×6動力車） |

**モデル化の境界：** 最高営業速度・加速度・減速度をkm/hとkm/h/sからm/sとm/s²に変換して毎フレーム積分。現在速度からの制動距離 `v²/(2a)` を使い常用制動を自動開始し、非常ボタンで非常減速度に切り替える。高速域の詳細な引張力曲線は資料にないため、**65km/hを境に速度に反比例して加速力が弱くなるゲーム上の近似**を使用（京王5000系の65km/hという境界値は実車の仕様値ではない）。曲線通過速度、勾配、荷重変動、運転時分、扉操作、編成や分岐器の車両限界、ポイント切替、閉塞・信号、電力消費は未実装。再生倍率はシミュレーション時間の倍率であり実車の性能を変えない。

**軌間について：** 名鉄と京王は実車の軌間が異なり、そのままでは同じ線路を走れない。現在の建設画面に軌間設定がないため、車両画面の試運転は性能を比較する仮想モードであり、両編成を物理的に直通可能と判定したわけではない。名鉄2200系の実編成長は約114mで、ゲーム上の120mはユーザー指定による共通規則。

車両情報の出典：[名鉄公式・2200系特別車](https://www.meitetsu.co.jp/train/guidance/first_class_car/)／[製造元・日本車輌製造の2200系紹介](https://www.n-sharyo.co.jp/business/tetsudo/pages/meit2200.htm)／[京王公式・5000系紹介](https://www.keio.co.jp/keiofan/museum/exist/)／[京王電鉄寄稿・5000系主要諸元（日本地下鉄協会『SUBWAY』2017年、PDF）](https://www.jametro.or.jp/upload/subway/UXQyxXDMDWrS.pdf)。名鉄の加減速度・軌間などメーカーサイトに数値のない詳細は[名鉄2200系主要諸元の整理](https://ja.wikipedia.org/wiki/名鉄2200系電車)、京王の営業最高速度は[京王5000系主要諸元の整理](https://ja.wikipedia.org/wiki/京王5000系電車_(2代))と照合。

**集客計算：** `population-kariya-2025.json`・`population-chiryu-2025.json`・`population-toyoake-2025.json` は上記国交省の「250m_mesh_2024_23_GEOJSON.zip」から刈谷市（市区町村コード23210）、知立市（23225）、豊明市（23229）の2025年推計総人口が正のメッシュをそれぞれ抽出したものです。`python3 extract_kariya_population.py <元ZIPのパス>` で3市分を再生成できます。各メッシュを4×4点に細分化し、各点を徒歩800m以内の**最寄りの設置駅1駅のみ**に割り当てます。距離0〜400mは1、400〜600mは0.65、600〜800mは0.30を掛けた人口が「潜在利用人口」です。この集客係数はゲーム独自の仮定であり、鉄道利用率の統計ではありません。道路距離・改札位置・運行本数・運賃・路線接続・商業施設への流動はまだ考慮していません。

**データの範囲：** 刈谷市人口153,200人・知立市人口72,861人・豊明市人口67,693人は2026年10月時点の各市公表人口、人口メッシュの刈谷市約155,197人・知立市約72,595人・豊明市約68,351人は2020年国勢調査を基準にした2025年の国交省推計であり、定義・年度が異なります。2026年町別人口CSVは出典として案内していますが、個別の町界ポリゴンや同CSVの人口割り当ては行っていません。全商店・全事業所の位置や現在の乗降者数を網羅したものではありません。現実の地下鉄計画に必要な道路・地質・工費等も未評価です。
